# Climate Projections – ACCESS-CM2 (CMIP6) for Baixo São Francisco, Brazil

This repository contains future climate projection maps for the Baixo São Francisco region (Brazil), generated using the ACCESS-CM2 model from CMIP6 and automated through generative AI tools integrated with QGIS.

## 📍 Region of interest

- **Area**: Baixo São Francisco, Northeast Brazil
- **Coordinates**: approx. -10.3° to -11.5° S, -36.5° to -37.8° W

## 🔬 Methodology

- **Climate model**: ACCESS-CM2 (CMIP6)
- **Scenarios**: SSP126, SSP245, SSP370, SSP585
- **Time periods**: 
  - 2021–2040  
  - 2041–2060  
  - 2061–2080  
  - 2081–2100

- **Variables**: 
  - Minimum temperature (Tmin)  
  - Maximum temperature (Tmax)  
  - Precipitation  

- **AI tools used**: 
  - ChatGPT (OpenAI)
  - GitHub Copilot

- **Processing**: QGIS with automated Python scripts for:
  - Raster batch processing
  - Map styling and classification
  - Layout generation and PNG export

## 📁 Repository contents

- `data/`: Raw and processed raster datasets
- `scripts/`: Python scripts for automation in QGIS
- `outputs/`: Final climate maps (.png) and layout templates (.qpt)
- `docs/`: Supplementary documentation
